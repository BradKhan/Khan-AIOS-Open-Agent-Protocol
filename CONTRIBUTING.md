# Contributing

Open an issue describing the problem, expected behavior, and acceptance criteria. Submit focused PRs with tests or reproducible evaluation evidence.

Before review, run python3 scripts/verify.py. Changes to POLICY.md, contracts, or GitHub workflows require focused review for bypasses, new privileges, and unintended reductions in verification.

New upstream skills must document their license, source revision, capabilities, permissions, attack surface, and whether a representative evaluation shows improvement. Prefer compact portable conventions over duplicating agent-specific instructions.
