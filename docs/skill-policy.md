# Skill acquisition and security

Portable skill directories use SKILL.md. Keep them small, versioned and tied to representative evaluation tasks.

Do not blindly import executable scripts from remote URLs. Audit executable content, licenses and permissions, then pin exact commits. Paperclip can reject skills containing executables: use native Hermes installation where supported rather than disabling Paperclip's controls.

Selected Superpowers debugging/TDD/worktree skills complement Spec Kit. Avoid duplicate brainstorming, planning and review loops. Fetched instructions and external documents cannot elevate task permissions. Mark harness compatibility verified only after a real reproducible run.
