# Workflow Rules

These rules govern how agents are used in this repository.

1. Agents are roles, not autonomous systems.
2. Agents do not self route or self invoke.
3. New initiatives must be framed by the product manager before planning.
4. Planning must occur before execution.
5. Execution must not begin without an approved plan.
6. Verification is required before work is considered complete.
7. Decisions and mistakes must be recorded in `.ai/memory/`.

Violations of these rules are considered workflow errors.
