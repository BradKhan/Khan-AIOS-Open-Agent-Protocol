# KhanOS

KhanOS is a sovereign AI engineering methodology.

It externalizes the internal workflow discipline used by the Anthropic engineering team
without locking users into proprietary tools, pricing, or providers.

It is built on a simple premise:

Models do not decide what matters.
Humans do.

KhanOS enforces:
- Explicit intent before execution
- Clear separation of reasoning roles
- Shared, versioned memory
- Verification as a first class requirement

It works with any capable model.
It works in VS Code, CLI tools, or web interfaces.
It survives tool churn.

This is not vibe coding.
This is engineering discipline, made portable.
